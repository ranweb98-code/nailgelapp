# Studio Noir · אפליקציית קביעת תורים ללק ג'ל

אפליקציית-אתר (PWA) בעברית בעיצוב כהה ואווירתי להזמנת תורים לסטודיו ציפורניים. הלקוחות בוחרים שירות, רואים יומן פנוי, קובעים תאריך ושעה, בוחרים תמונות השראה מהגלריה, וממלאים פרטים. בעלת העסק מקבלת אימייל על כל תור חדש (כולל ההשראה שנבחרה), הלקוחה מקבלת אישור, ונשלחת תזכורת אוטומטית לפני המועד. כולל פאנל ניהול מלא.

ניתן להוסיף את האתר למסך הבית בטלפון ולהשתמש בו כמו אפליקציה.

## טכנולוגיות

- **Next.js 15** (App Router) + **TypeScript** + **Tailwind CSS**
- **Prisma** + **SQLite** (קובץ מקומי, אפס הקמה)
- **Resend** לשליחת אימיילים (עם מצב preview ל-console כשאין מפתח)
- **PWA** מלא: manifest, service worker, אייקונים, ופרומפט התקנה

## הרצה מהירה

```bash
npm install
npm run db:push    # יצירת מסד הנתונים
npm run db:seed    # זריעת שירותים ושעות עבודה
npm run dev        # http://localhost:3000
```

(אם הרצתם `npm install` כבר נוצר ה-Prisma Client אוטומטית.)

## משתני סביבה (`.env`)

הקובץ `.env` כבר מוגדר עם ערכי ברירת מחדל לדמו. עיקריים:

| משתנה | תיאור |
|-------|-------|
| `ADMIN_PASSWORD` | סיסמת הכניסה לפאנל הניהול (ברירת מחדל: `gel1234`) |
| `RESEND_API_KEY` | מפתח Resend לשליחת אימיילים אמיתיים. ריק = מצב preview (האימיילים מודפסים ל-console) |
| `OWNER_EMAIL` | כתובת בעלת העסק לקבלת התראות על תורים חדשים |
| `EMAIL_FROM` | כתובת השולח (דורש דומיין מאומת ב-Resend) |
| `NEXT_PUBLIC_VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` | מפתחות Web Push להתראות באפליקציה המותקנת |
| `REMINDER_HOURS_BEFORE` | כמה שעות לפני התור לשלוח תזכורת (ברירת מחדל: 24) |

## מסכים

- **`/`** — דף הבית: hero, השירותים, גלריית השראה, שעות הפעילות ופרטי קשר.
- **`/book`** — זרימת קביעת התור (שירות → תאריך ושעה → השראה → פרטים → אישור).
- **`/admin`** — פאנל הניהול (דורש סיסמה): רשימת תורים עם ההשראה שצורפה, אישור/ביטול.
- **`/admin/settings`** — הגדרות: שעות עבודה, שירותים ומחירים, גלריית השראה, ימים חסומים.

## עיצוב
עיצוב כהה ואווירתי (glassmorphism) עם רקע יער מעורפל, שם בסריף אלגנטי, ותמונות ציפורניים. וידאו ההירו נמצא ב-`public/videos/hero.mp4` (החלפה: שמרו את אותו שם קובץ). שאר התמונות ב-`public/images/` (רקע וגלריית `inspo/`) וניתנות להחלפה.

## אימיילים אמיתיים (אופציונלי לדמו)

1. נרשמים ב-[resend.com](https://resend.com) ומקבלים מפתח API.
2. מאמתים דומיין (או משתמשים ב-`onboarding@resend.dev` לבדיקות).
3. ממלאים ב-`.env` את `RESEND_API_KEY`, `EMAIL_FROM`, ו-`OWNER_EMAIL`.

ללא מפתח — האפליקציה עובדת במלואה והאימיילים מודפסים ל-console (נוח לדמו).

## התראות Push (PWA)

מי שמתקין את האפליקציה למסך הבית **חייב** לאפשר התראות. בלי זה מוצג מסך חסימה.

1. יוצרים מפתחות: `npx web-push generate-vapid-keys --json`
2. ממלאים ב-`.env`:
   - `NEXT_PUBLIC_VAPID_PUBLIC_KEY`
   - `VAPID_PRIVATE_KEY`
   - `VAPID_SUBJECT` (למשל `mailto:owner@example.com`)
3. אחרי התקנה + אישור הרשאות:
   - **לקוחה** מקבלת Push על אישור תור, אישור/ביטול ותזכורת
   - **בעלת העסק** (אחרי כניסה לפאנל באפליקציה) מקבלת Push על תור חדש

הערה: ב-iPhone נדרש iOS 16.4+ והאתר חייב להיפתח מ"הוסף למסך הבית".

## תזכורות אוטומטיות

- **בפיתוח**: מתזמן פנימי בודק כל 5 דקות (`instrumentation.ts`, מבוקר ע"י `ENABLE_CRON`).
- **בפרודקשן (Vercel)**: `vercel.json` מגדיר Cron שקורא ל-`/api/cron/reminders` כל שעה.

## מעבר לפרודקשן

לפריסה אמיתית מומלץ להחליף את SQLite ב-Postgres (למשל Neon): משנים את `provider` ו-`DATABASE_URL` ב-`prisma/schema.prisma` ומריצים `prisma db push`.
